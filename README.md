# 🚀 PortfolioAI – AI Powered Portfolio Builder

Build a professional developer portfolio in minutes using AI.

PortfolioAI is a full-stack MERN application that allows users to create, manage, and publish beautiful portfolio websites. Users can manage their profile, projects, education, skills, certificates, and generate portfolio content with AI. The application also provides multiple portfolio templates and analytics.
